# Setting up the Orbit Home Router

Unbox the router and connect the WAN port to your modem with the supplied Ethernet cable.
Plug in the power adapter. The status light blinks amber while the router boots and turns solid white when it is ready.

Open the Orbit app and scan the QR code on the bottom of the router to start setup.
The default network name is printed under the QR code. Setup takes about five minutes.
